# image-bot

**AI generation core + a Telegram bot that feels good to use.**

Два слоя, один продукт:
- **`core`** — универсальный движок генерации: картинки, текст, видео, TTS. Провайдеры меняются как картриджи, лимиты и хранилище встроены.
- **`tgbot`** — профессиональная Telegram-обёртка: личный чат и работа в чужих группах.

Открытый, бесплатный для пользователей, с честными лимитами.

## Что умеет (план v0.1)

| | Личка | Группа |
|---|---|---|
| Картинка по тексту | текст → фото | `/gen`, reply, @упоминание |
| Редактирование фото | фото + подпись | reply на фото + инструкция |
| Улучшение промпта | кнопка «✨ Ещё лучше» | автоперед событием генерации |
| Текстовый ИИ (чат) | диалог с памятью | — |
| Видео, TTS | задел в ядре | — |

## Быстрый старт

```bash
cp .env.example .env   # вписать BOT_TOKEN
docker compose up -d
```

Хочешь генерацию по **подписке xAI Grok Build** (не API-ключ)? Поставь
`IMAGE_PROVIDER=grok_build`, `BOT_OWNER_ID=<твой id>` и отправь боту `/login`:
он проведёт через device-code вход, сессия сохранится в volume и переживёт
перезапуск контейнера.

Дальше — [docs/README.md](docs/README.md) (EN) · [docs/ru/README.md](docs/ru/README.md) (RU).

## Слои

```
┌─────────────────────────────────────────┐
│ tgbot        UI, UX, сцены, группы      │  ← знает про Telegram
├─────────────────────────────────────────┤
│ core         домен: медиа, лимиты, i18n │  ← не знает про Telegram
│  · providers (Pollinations, …)          │
│  · text / image / video / tts services  │
│  · prompting  (prompt-enhance, стили)   │
│  · mcp        (текст → вызов генерации) │
│  · ratelimit, storage, i18n             │
├─────────────────────────────────────────┤
│ SQLite, HTTP                             │
└─────────────────────────────────────────┘
```

Ядро не импортирует aiogram. Обёртка не импортирует HTTP-провайдеров напрямую.
Граница слоёв — протоколы из `core/` (см. [docs/en/architecture.md](docs/en/architecture.md)).
