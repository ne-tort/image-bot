# Roadmap

## v0.2 — доводка картинок
- Агрегация альбомов для правки (паттерн job-queue из Eugene-референса)
- `/history` — инлайн-галерея с переиспользованием file_id
- Управление seed + флоу «тот же seed, новый промпт»
- Ретраи с backoff на ProviderError.Transient

## v0.3 — текст и MCP-цикл
- Полный цикл tool-use в TextService (multi-turn, протокол TOOL)
- Персистентная память диалога на юзера (таблица `messages`)
- Подсказки промптов из истории

## v0.4 — видео и TTS
- VideoService: async-задача → прогресс → отправка
- TTSService: команда /say, голосовые ответы

## v0.5 — эксплуатация
- Режим webhook (публичный URL), структурные JSON-логи
- /admin для владельца: статистика, broadcast
- Опциональные ключи API на юзера (паттерн PromptArt)
- Профиль Postgres для крупных установок
