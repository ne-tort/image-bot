# UX в Telegram

## Личка

- Голый текст → картинка. Без /команды (паттерн PromptArt).
- Фото + подпись → правка.
- Под каждым результатом: ✨ Сделать лучше / Ещё раз.
- Только inline-клавиатуры. Reply-клавиатуры — никогда: они крадут
  клавиатуру юзера и не работают в группах.
- Статус «Рисую…» → удаляется после успеха; при ошибке заменяется текстом.

## Группы

Золотые правила (из референсов capslock/Eugene):

1. **Только явные триггеры**: `/gen`, `/edit` (reply на фото), @упоминание
   или reply на бота. Никогда не реагировать на произвольные сообщения.
2. **Privacy Mode должен быть выключен** (BotFather), иначе бот ничего
   из этого не видит. Описано в deployment.md.
3. `my_chat_member`: добавили → короткое приветствие + включение;
   удалили → чат помечается выключенным. Никаких простыней текста.
4. Гейты админов: `/enable`, `/disable` — только для админов.
5. Дневной потолок на чат (GROUP_DAILY_LIMIT), чтобы одна группа
   не съела квоту всех.

## Тексты ошибок

У каждого сценария — человеческое сообщение (core/i18n/messages.py):

| Случай | Тон |
|---|---|
| Свой дневной лимит | «Лимит на сегодня исчерпан 🌙 …» — честно, говорит когда сброс |
| Свой часовой лимит | «Полегче 🚀 …» — коротко, с юмором |
| 429 провайдера | берем вину на себя, даём время повтора |
| Фильтр контента | предложить переформулировать, без нотаций |
| Провайдер лежит | пригласить повторить через минуту |

Никогда: сырые исключения, коды ошибок, «Что-то пошло не так».
